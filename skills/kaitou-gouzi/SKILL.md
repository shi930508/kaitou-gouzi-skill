# 开头钩子：短视频前 2–6 秒

钩子就是视频的前 2–6 秒。观众在这段时间里同时吸收画面、文字和声音，凭本能决定划走还是留下。短视频是平台推给观众的，不是观众主动点开的，所以留不留全凭钩子。观众在第 4 秒划走，后面再好的内容也等于黑屏。打磨一条视频时，值得把 30%–40% 的力气花在开头上。

本技能的方法论来自 Kallaway《短视频钩子工作坊》，已按中文短视频和房产场景改写。

## 一、三条底层原理（写、改、拆都靠它们）

### 1. 钩子是四件套，不只是第一句话

| 优先级 | 组成部分 | 指什么 |
|---|---|---|
| 1 | 屏幕文字 | 屏幕上的大字、花字、手举纸板上的字 |
| 2 | 画面 | 出镜口播（A-roll）、空镜/实拍/截图/动图（B-roll） |
| 3 | 口播 | 嘴里说的话 |
| 4 | 音频 | 背景音乐、音效 |

人看和读比听快，所以文字和画面先被接收，比口播更重要。观众注意力的走向是：画面/文字 → 口播 → 画面/文字。所以没有口播的视频也能火，口播好但画面和文字弱的视频却很难火。

**最大对齐**：四件套必须说同一件事。口播讲"首付"，画面却是小区大门的空镜，字幕又是"贵阳楼市真相"，三样东西各说各的，观众就会困惑。这叫"理解损失"，观众一困惑就划走。500 播放和 50 万播放的差距，往往就差在对不对齐。

### 2. 心理公式：钩子 = 对靶 + 好奇循环

观众刷视频时，下意识在找两种价值：**有用**（能解决我的问题）和**有趣**（能给我情绪起伏）。钩子要在 2–6 秒里让观众确认两件事：

- **对靶**：这条视频讲的事和我有关。
- **好奇循环**：我心里冒出一个问题，想知道答案。

做到对靶的四个手段：
1. **快速语境**：第一句话就说清视频讲什么。"大家好我是鹏飞""今天跟大家聊一聊"会把最值钱的第一秒浪费掉。
2. **清晰**：用短词、大白话，不用行业黑话（"去化""公摊系数""限价备案"之类，除非目标观众本来就懂）。
3. **提炼**：用最少的字说清楚。多加几个字能消除歧义就加，否则删。
4. **说"你"不说"我"**：说"你"，观众直接代入；说"我"，观众得先判断"他的事跟我有没有关系"，这一停顿就可能划走。例外：亲身经历的故事如果本身极有共鸣（"我在花果园亏了 40 万"），可以用"我"。

### 3. 好奇心来自反差

反差 = 观众原以为的（普遍认知）和你给出的（反常识观点/新信息）之间的距离。距离越大，越想看下去。

- **明示反差**：把普遍认知直接说出来再推翻。"都说观山湖贵，但同样 150 万，在这里能买到比老城区大 30 平的房子。"降低误解，但会筛掉一部分人。
- **暗示反差**：不说普遍认知，只抛出"不一样的"那一面，让观众自己补全。"贵阳买房，真正懂行的人都在看这一个数字。"覆盖面更广。

**100 人测试**：一屋子 100 个贵阳买房人，有几个已经知道你要说的？100 个都不知道，反差最大；50 个已经知道，反差就弱了。写完口播先做这个测试。

反差的常见来源：之前 vs 现在、大家以为 vs 实际、别人这样做 vs 懂行的人那样做、普通人 vs 有钱人、不知道 vs 知道、平静 vs 突发状况。

## 二、先判断用户要哪种服务

| 用户给了什么 | 模式 |
|---|---|
| 选题、主题、口播稿、一句想法，要开头 | **A. 写新钩子** |
| 自己写好的开头 / 已发视频的开头，问行不行、要改 | **B. 诊断改写** |
| 别人的爆款视频开头（文字、截图描述、字幕），要拆解 | **C. 拆解对标** |

拿不准时按 A 做。缺了没法写的信息（连主题都没有）才提问，尽量用选择题。账号没说就默认「鹏飞买房参考」，平台没说就按抖音、视频号、小红书三端通用来写。

### 账号速查（默认房产场景）
- **鹏飞买房参考**：真人主号。站买方立场的贵阳本地买房参考，口吻直接、敢说真话。
- **鹏飞聊升学买房**：幼升小、小升初倒逼买房决策的贵阳家庭。钩子从孩子入学时间点切入。
- **闻野在贵阳**：AI 虚拟 IP，在贵阳生活的年轻房产从业者。栏目有"闻野的客户""闻野下班后""闻野问鹏飞"。口吻更生活化，钩子里不出现真实全名。

用户给的是其他行业，就按那个行业的观众来写，不要硬套房产。

## 三、模式 A：写新钩子

### 第 0 步：提炼输入（不用展示）
- **观众**：刚需首套、改善换房、升学家庭、外地来贵阳的年轻人、手里有房想卖的……
- **价值**：看完能得到什么（避坑、省钱、判断方法、内幕信息）或者什么情绪（震惊、扎心、爽）
- **普遍认知 vs 你的观点**：反差在哪
- **手上素材**：用户提到的楼盘实拍、户型图、数据截图、出镜条件。没提就按"能出镜 + 能用手机补拍"来设计

### 第 1 步：写口播（1–4 句，最好 1–2 句）
从下面 7 种结构里挑合适的，一组方案至少覆盖 3 种不同结构：

| 结构 | 怎么起 | 房产示例 |
|---|---|---|
| ① 预言家 | 某件事发生了，未来会不一样 | "这条地铁一通，贵阳买房的逻辑要变了。" |
| ② 实验/现场 | 现场展示、实测、实地验证 | "我拿卷尺量了这套房的实际面积，和合同差了多少？" |
| ③ 教学 | 给方法、给工具、给步骤 | "看贵阳二手房，先问这 3 个问题，能避开一半的坑。" |
| ④ 揭秘 | 揭开不为人知的规则或真相 | "售楼部不会主动告诉你，样板间的层高是加过的。" |
| ⑤ 反常识 | 第一句直接抛出反直觉观点 | "在贵阳，越早买房的人，可能亏得越多。" |
| ⑥ 对比 | 两个或多个选项比较 | "同样 120 万，老城区和观山湖，到底该选哪个？" |
| ⑦ 提问 | 抛出观众想知道答案的问题 | "为什么贵阳很多老师都在花果园买房？" |
| ＋ 原始冲击 | 可以叠加在任何一种上：一个让人停住的词、动作或"你看这个" | "你看这个窗户……这房子千万别买。" |

万能骨架：**"如果你想 [解决某个问题]，就 [做某件事]。"** 写不出来时先用它兜底。

### 第 2 步：配画面
画面要**兑现口播**：说"量面积"就拍卷尺量，说"这个窗户"就怼窗户特写，说"两个片区比较"就分屏。没有合适素材时有三种选择：
1. 手机补拍一段能直接说明口播的 B-roll
2. 用 AI 生成图片或视频
3. 本人出镜口播（A-roll）。这样屏幕文字的压力更大，要写得更狠

出镜口播的加分项：
- **初始运动**：开头镜头离脸很近，再往后靠；或者边走边说
- **被动动作**：边做一件事边说另一件事（边开车、边看房、边翻户型图），手上的动作能撑住注意力
- 表情有精神，别像在念稿

B-roll 的加分项：每 1–2 秒换一次画面，但别快到看不清；用箭头、圆圈、高亮把视线引到关键位置；画面要有颜色、有运动、对比强。画面里展示的东西要真的够"惊艳"，口播吹了，画面却很平常，好奇心反而被打掉。

### 第 3 步：写屏幕文字
- 字少，最好 ≤12 字，可拆两行
- 能引发好奇或情绪（震惊、意外、扎心）
- 和口播说同一件事，可以是口播的浓缩，也可以补一个口播没说的数字
- 字大、字体易读、加底色或描边；放在人物视线高度附近，避开平台按钮和标题遮挡区
- 只有出镜口播时，屏幕文字是第一抓手

常用文字骨架：直接重复口播关键句 / "[某人] 做了 [某事]" / "[某事] 的真相" / "[人群]，别再 [做某事] 了" / 直接写一个震撼数字

### 第 4 步：定音频
四选一：无音乐无音效 / 只有背景音乐 / 只有音效 / 音乐加音效。音乐的情绪要和内容一致：避坑类用紧张的，干货类用轻快的，故事类用有情绪起伏的。用一句话说明风格即可，不要指定具体曲名。

### 第 5 步：自检后再交付
对每套方案过一遍"质量红线"（见第六节）。不合格的直接重写，不要交给用户。

### 模式 A 输出格式

```
⭐ 首推方案（结构：⑤ 反常识）
口播：……
屏幕文字：……
画面：……
音频：……
为什么能钩住：对靶=……；反差=普遍认知「……」vs 你的观点「……」

备选 2（结构：③ 教学）
口播：……
屏幕文字：……
画面：……
音频：……
一句话：……

备选 3 / 4 / 5 ……

📋 拍剪自检（针对首推方案）
□ 第一句话就说清讲什么
□ 画面能兑现口播：……（写出这条的具体要求）
□ 屏幕文字在信息流里不被挡
□ 静音看一遍 / 闭眼听一遍 / 正常看一遍，三遍都知道"讲什么 + 为什么要看下去"

🎯 结尾留资句（可选，配首推方案）
……
```

默认交付 1 套首推加 4 套备选。用户要几套就给几套。备选方案的解释压缩成一句话，不写长篇分析。

### 结尾留资句怎么写
开头决定观众看不看，结尾决定观众留不留联系方式。所以每次附一句可选的结尾留资话术，配首推方案：
- **呼应开头的承诺**：开头说"帮你筛片区"，结尾就说"把你的预算和上班地点打在评论区，我帮你筛"
- **只要一个具体信息**：预算、孩子哪年入学、看中哪个片区、在哪上班，选一个。观众回复的门槛越低越好
- **给确定的回报，不做承诺**：说"我帮你看来不来得及""我帮你算这笔账"，不说"保证上学""包你买到便宜房"
- **口语、一句话、不硬广**：不说"欢迎咨询""添加微信"，私信或评论引导即可

示例：
- 刚需选片区："首付多少、在哪上班，评论区打出来，我帮你把不该看的片区先划掉。"
- 升学号："孩子哪年入学、预算多少，评论区告诉我，我帮你看还来不来得及。"
- 二手房避坑："看中了哪套二手房，把小区名私信我，我帮你先过一遍这几个坑。"

## 四、模式 B：诊断改写

1. **还原四件套**：把用户给的开头拆成口播、屏幕文字、画面、音频。用户没说的部分标"未提供"，并按口播推测他大概会怎么拍。
2. **逐项判定**（每项给 ✅ / ⚠️ / ❌ 加一句原因）：
   - 快速语境：第一句话能否让人知道讲什么？
   - 清晰提炼：有没有废话、黑话、能理解成两种意思的句子？
   - 视角：是"你"还是"我"？
   - 反差：有没有明示或暗示的反差？过不过得了 100 人测试？
   - 四件套对齐：文字、画面、口播是不是在说同一件事？
   - 价值速度：观众在第几句才知道自己能得到什么？超过第 2 句就算慢
3. **一句话病因**：点出最致命的那一个问题。
4. **改写**：给 3 版改写，每版都是完整四件套，标明修掉了哪个病因。至少一版保留用户原来的核心意思，只修结构；另外两版可以换结构。
5. 附上和模式 A 一样的拍剪自检和一句结尾留资句。

常见病因（对照着找）：
- 开头浪费在"在我看来""大家好""今天聊聊"上
- 几个信息点互相不挨着，看完开头不知道往哪走
- 屏幕文字一套、口播一套、画面又一套
- 价值来得太慢，第三句才露出要讲什么
- 画面没兑现口播：说"惊人"，展示的东西很普通
- 文字太长，在屏幕上停留的时间读不完
- 用"问答式"：屏幕上是问题，口播直接从答案讲起，观众得先读完问题才跟得上
- 罗列症状式开头："你现在是不是这样的状态……"已经被用烂了，直接打买房决策上的痛点

## 五、模式 C：拆解对标爆款

1. **四件套还原**：口播 / 屏幕文字 / 画面 / 音频，各写一行。用户只给了口播文字，就只拆口播，并说明画面信息缺失会影响判断。
2. **结构归类**：属于 7 种结构里的哪一种，有没有叠加原始冲击。
3. **为什么有效**：对靶靠什么实现（第一句给了什么语境）；反差是明示还是暗示，普遍认知和反常识观点各是什么；四件套怎么互相加强。
4. **可复用骨架**：把这个开头抽象成一句带空位的模板，比如"[某人群] 都在 [做某事]，但 [反常识结果]"。
5. **换成你的版本**：用骨架给用户的账号写 2–3 个四件套钩子（默认贵阳房产），附上和模式 A 一样的拍剪自检，再附一句结尾留资句。
6. **调研提醒**（一行就够）：对标账号最好按播放量排序看最近一年的爆款，每 2–4 周复盘一次。

## 六、质量红线（每套方案交付前都要过）

1. 第一句话就有快速语境。没有就重写。
2. 不出现"大家好""今天跟大家聊""在我看来"这类开场。
3. 能用"你"就不用"我"（亲身故事例外）。
4. 有明确的反差，能说出普遍认知和你的观点各是什么。
5. 口播、屏幕文字、画面说同一件事。
6. 读一遍不可能被理解成别的意思。
7. 口播 1–4 句，念出来顺口，没有黑话。
8. 痛点打在买房决策上（钱、风险、选择），不为了戳痛而戳痛，不贩卖焦虑。

### 房产内容合规
- 不用"最、第一、顶级、唯一"形容楼盘或服务。表达个人观点（"我认为最该看的是……"）可以。
- 不承诺升值、收益、"稳赚""闭眼买"。
- 不承诺学位、划片、入学结果，升学号尤其注意。
- 不把规划中的地铁、学校、商业说成已确定。
- 不点名贬低具体竞品楼盘。
- 数字、价格、面积只用用户给的。用户没给的，用【X万】【X平】占位，并在最后提醒补充。
- 闻野是 AI 虚拟 IP，AI 身份标注放在视频说明里，不放进钩子文字。

## 七、迭代

- 用户说"更狠一点 / 更温和 / 更口语 / 换个角度"时，换一种结构重写，不要只在原句上换几个词。
- 用户只要改一条，就只改那一条，不重发全部。
- 用户问怎么判断钩子好不好：看平均观看时长。比账号平常高，说明钩子起作用了。最稳的办法是同一条视频做 2–4 个不同开头，分别发布对比，不行就过几周换开头重发。
